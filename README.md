# 💻 Dasar Pemrograman Lab (SI-FT-UNMUL)

Repository ini berisi kumpulan modul latihan, tugas praktikum, implementasi algoritma, dan proyek mini untuk mata kuliah **Dasar Pemrograman** (Semester 1 - Program Studi Sistem Informasi, Universitas Mulawarman).

---

## 🎯 Capaian Pembelajaran (Sub-CPMK)
- **CPMK 032**: Mampu menggunakan berbagai alat pengembangan sistem dan menerapkan konsep pemrograman dasar.
- Mengidentifikasi dan mengklasifikasikan kebutuhan fungsional sistem melalui kode.
- Mengimplementasikan alur logika program, penanganan memori, struktur data, dan algoritma pencarian/pengurutan secara efisien.

---

```text
